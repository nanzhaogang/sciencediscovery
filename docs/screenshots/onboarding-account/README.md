# 安装引导与账号界面 — 修改前后对照

用于 PR 评审的截图存档。**修改前**取本次改动的父提交 `d13cead9`，**修改后**取本分支的构建；两边都在 Windows 上以 1600×1000 视口渲染，接口由 e2e 的确定性 mock 提供（账号、积分、流水均为夹具数据，非真实账号）。

| 对照 | 页面 / 流程 | 修改前 | 修改后 |
| --- | --- | --- | --- |
| `01-login-*` | 账号登录入口 | 顶部“华为账号登录 / 自定义模型”切换页签，标题“登录后继续”，底部一行服务条款提示 | 去掉页签，标题“账号登录”，说明合并为一段（积分 → 免费模型 → 跳转说明），右侧新增“暂不登录，配置自定义模型”按钮，整块内容下移 |
| `02-model-*` | 自定义模型配置 | 页签切换进入，标题“配置你的模型”，标题下有一段接口地址说明；只有“测试并继续”（胶囊圆角） | 标题“自定义模型配置”，删除说明段与序号；左侧新增“返回上一步”，两个按钮统一 6px 圆角 |
| `03-account-*` | 个人中心 | 内容铺满窗口；“累计获得”取整为 `1,000`，“累计消耗”取服务端字段 `401.109` | 与设置页一致的 1120px 居中阅读列；累计获得 `1,000.999`、累计消耗 `402.108`（由 获得 − 可用 推导，三数恒等） |
| `04-ledger-*` | 积分流水上限 | 1500 条流水可翻到第 15 页，无任何提示 | 最多读取/展示 1000 条：第 10 页为末页，下方提示“仅显示最近 1000 条流水，更早的记录不再列出。” |
| `05-signout-*` | 退出华为账号 | 点击“退出登录”立即退出，直接落到未登录面板 | 先弹出确认弹窗：“确认退出华为账号”，正文前带感叹号三角，取消/退出登录等宽，无顶部小标签 |
| `06-models-signedout-*` | 设置 › 模型（未登录） | 积分模型仍可展开、测试、删除，无状态标识 | 行置灰并标注“登录后可用”，不提供展开/测试/设为主模型/删除 |
| `07-signin-result-*` | 华为登录回跳结果 | 停留在“登录成功”页，必须再点一次“进入工作台” | 回跳结算后自动进入工作台，不再有中间确认页 |

说明：

- 登录入口的对比同时体现文案与布局两处改动；`01-login-after.png` 中按钮与标题的垂直位置即最终落位。
- 本次改动的账户服务侧（流水按获得/消耗各保留 1000 条、签到计数改为独立表）没有独立页面，其界面表现由 `04-ledger-*` 与个人中心数据一致性体现。
- 截图脚本仅用于生成这些图片，不随分支提交；图片对应的测试断言在 `apps/desktop/e2e/onboarding-account.spec.ts`。
